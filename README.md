# berlin-flood-dilemma
Scripts and data related to a research article on the collective action problem in the context of decentralized urban pluvial flood adaptation.

The flowchart below visualizes the order of processing scripts with their respective input and output. The Python environment can be built from the *.yml* file, while the used R libraries are documented in *R_sessionInfo.md*.
